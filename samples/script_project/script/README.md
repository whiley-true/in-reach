# Sample

Every player scores a point per second and runs 50% faster; the round ends at `SCORE_TO_WIN` points.

This file is the script's own README: `in-reach docs` (and the IDE's Documentation panel) put it at the top of the
generated overview, `build/docs/overview.md`. A block can have one too (`blocks/setup.md`), and so can a module
(`modules/scoring/README.md`).
